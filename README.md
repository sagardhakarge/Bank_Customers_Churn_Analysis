# 🏦 Bank Customer Churn Analysis

> An end-to-end data analytics project to understand customer churn patterns using Python, SQL Server, and Power BI.

## 📊 Project Overview

Customer churn is an important challenge for banks because losing customers can affect revenue, customer relationships, and long-term growth.

This project analyzes bank customer data to understand customer churn patterns and identify customer characteristics associated with churn.

The project follows a complete data analytics workflow:

**Python → EDA → SQL Server → Power BI**

---

## 🎯 Project Objectives

- Clean and prepare the customer dataset.
- Perform exploratory data analysis using Python.
- Identify patterns related to customer churn.
- Perform SQL-based customer analysis.
- Build an interactive Power BI dashboard.
- Present meaningful business insights through visualizations.
